# Programa---Python-
Problema 3: Reabastecimiento de inventario (Python)  Programa que revisa una matriz de inventario con el formato [Código, Nombre, Stock actual, Stock mínimo] y calcula cuántas unidades hay que pedir de cada artículo. Si el stock actual es menor que el mínimo, la cantidad a pedir es la diferencia. Si es mayor o igual, es cero.
